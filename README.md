# Urban Legend

A mobile-friendly shooter game built with HTML, CSS, Tailwind, and plain JavaScript.

## Features

- Login and account creation (localStorage)
- Home screen with highest score and longest time
- Drag/joystick movement, auto-shooting, enemy waves
- Score, HP, and timer

## How to run

Open `index.html` with Live Server, or visit the GitHub Pages link.

## Built with

HTML, CSS, Tailwind CDN, JavaScript
